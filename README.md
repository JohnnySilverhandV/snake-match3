# 蛇形三消 SNAKE://MATCH v1.0

贪吃蛇 × 三消的融合小游戏。单文件 HTML，零依赖，双击 `snake-match3.html` 即可玩，也可直接部署为静态站点。

在线试玩：https://snake-match3.app.workbuddy.host/?sharecode=WYM5RVJC46

## 玩法

蛇身固定三节「钢甲」起步，钢甲色永远不会刷出食物，也不参与消除。

场上有三类食物：

| 类型 | 外观 | 效果 |
| --- | --- | --- |
| 彩色食物 | 1~3 节相连的发光色块，形状随机 | 吃掉后同色色块接到蛇尾 |
| 叠层食物 | 单格、错位堆叠的同色卡片，标 `×N` | 一次吃下 2~4 节同色，颜色刻意与场上某组彩色食物相同 |
| 干扰食物 | 单格、暗紫斜纹 | 消不掉的死块，挤占蛇身；被相邻消除挤碎时 +15 分 |

### 消除规则：尾连制

- 吃到的色块挂在**蛇尾**，只有**吃的颜色与「吃之前」蛇尾颜色相同**才触发结算。
- 蛇尾同色凑满 **3 节及以上** 整段消除；异色块（例如绿尾吃黄色三连块）不会自爆，只挂在尾上存着。
- 消除后若新蛇尾又是 ≥3 的同色段，继续连锁 —— 连锁方向是从尾往头。

### 称号

- 多连：3 连「正常消」· 4 连 **good!** · 5 连 **amazing!** · 6 连以上 **unbelievable!**
- 连杀：连锁 2 次 **双杀** → 3 次 **三杀** → 4 次 **四杀** → 5 次 **五杀** → 5 次以上 **超神**

### 计分

- 基础分 `30 + (连数 - 3) × 20`，乘以当前连锁波次（上限 ×8）。
- 吃彩色食物 10 分/节，叠层 15 分/节，干扰块 0 分；挤碎干扰块每个 +15。
- 速度随分数缓慢提升。

## 操作

- 键盘：`↑ ↓ ← →` 或 `WASD` 转向，`空格` 暂停/开始，`Enter` 重开
- 移动端：棋盘上滑动转向，或用屏幕方向键
- HUD 的「蛇身色序」条会高亮**尾连段**，右侧显示「尾连 x/3」，方便规划下口吃哪个颜色

## 连杀阵型小抄

尾连制下，连锁从尾往头推进，所以阵型是**一串各 ≥3 节的同色段**：

```
AAA BBB CCC DDD EE   ← 尾连 E=2，再吃 1 节 E
→ EEE 炸 → DDD 炸 → CCC 炸 → BBB 炸 → AAA 炸 = 五杀
```

再往前垫一段就是 6 波 **超神**。干扰块可以夹在段与段之间当垫片，连锁波经过时会被挤碎。
